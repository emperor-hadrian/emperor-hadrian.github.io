Loading Screen Pranks - Hadrian Ward

Concept

I was once waiting for an email to load on my phone and I thought to myself, "how long would people wait for the spinning wheel of death before giving up?".

First trial, at Camden Hills Regional HS

On April 1st 2023 I made a very simple website on the raspberry pi that claimed to be a "student survey for a research project". It had a loading GIF and some javascript that would ping the server every 1 or 2 secs (don't remember). It also tracked devices so if someone closed the tab then reopened it it would still track the same person. I don't remember if the original JS tracked whether the tab was in-focus. Original analysis is not accurate because the server was buggy and more than half the total time for each client is 0 seconds. In a funny coincidence the AP Statistics class were also emailing people with legitimate surveys around the same time which I didn't know about but probably made my loading screen more convincing.

Second trial, at MSSM

On april fools 2024 I reused the html from 2023 on the raspberry pi and sent an email about a research survey. This time I rewrote the server in rust instead of python and it wasn't buggy anymore. I also had a bash script to live analyze the results that I could run over SSH.
